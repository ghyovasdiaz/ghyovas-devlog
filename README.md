## 🌟 Fitur Utama Blog

- **Urutkan Minggu**: Dropdown untuk melihat dari Minggu Terbaru (13 → 1) atau Minggu Terawal (1 → 13).
- **Interactive Post Reader Modal**: Klik kartu minggu apa saja untuk membaca:
  - Ringkasan aktivitas mingguan
  - **Tabel log kegiatan harian (Senin - Jumat)** persis sesuai dokumen resmi
  - Tugas & tanggung jawab utama
  - Kendala yang dihadapi & solusi yang diterapkan
  - Pelajaran berharga (*Key Learnings*)
  - Rencana minggu selanjutnya
- **Pencarian Spotlight (🔍)**: Cari catatan magang secara instan berdasarkan kata kunci, tanggal, nama role, atau topik.
- **Formulir Catatan Baru**: Tambahkan entri log mingguan langsung dari browser dengan penyimpanan otomatis di `localStorage`.
- **Desain Modern & Responsif**: Menggunakan font modern *Inter* & *Plus Jakarta Sans*, tata letak bersih, palet warna *Emerald & Sage*, dan dukungan penuh *Dark Mode*.

## 🚀 Cara Menjalankan

Cukup klik ganda (double-click) file **`index.html`** di File Explorer, atau jalankan melalui server lokal:
```powershell
python -m http.server 8080
```
Buka browser di `http://localhost:8080`.
